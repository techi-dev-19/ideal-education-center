# Local images

Abhi project images ko original site ke URLs se load karta hai (`src/data/site.js` -> `IMAGES`).
Agar aap images apne project me rakhna chahte ho:

1. Images download karke is folder me daalo (e.g. `logo.png`, `philosophy.png`).
2. `src/data/site.js` me URL badal do: `'/images/logo.png'`.
